# download-engine 外部契约（yt-dlp）

## Scope

- 本文件是应用与 `yt-dlp` 之间的完整契约：**argv 参数矩阵**、**stdout/stderr 行格式**、**退出码语义**。
- 二进制来源与版本由 `toolchain` 域管理；本文假定 `bin_dir` 中存在 `yt-dlp`（Windows 为 `yt-dlp.exe`）。
- 所有 flag 顺序固定为「基础 → 进度 → 网络 → 认证 → 字幕 → SponsorBlock → 格式 → 输入过滤 → 输入 → 输出 → 位置 → URL」。

## Conventions

- 值来源统一为三态：`Config`（全局设置）→ `DownloadOverrides`（组级覆盖）→ 实际 argv；合并函数 `resolve_with_patch`。
- `None`/`null` 一律表示"使用全局值"，空字符串表示"显式置空"（仅少数 flag 有意义）。
- 所有参数值都来自受控枚举、模板渲染结果或用户显式输入；**不拼接 shell 命令**（直接 `Command.args`），因此无注入面。

## 基础与执行环境

| 参数 | 值 | 来源 | 说明 |
| --- | --- | --- | --- |
| `--encoding` | `utf-8` | 固定 | 保证跨平台输出编码一致 |
| `PATH`（env） | `{bin_dir}{; 或 :}{原 PATH}` | `PathsManager.bin_dir` | 让 yt-dlp 能找到同目录的 ffmpeg |
| cwd | 继承应用进程 | — | 输出路径由 `-o` 决定，不依赖 cwd |

## 进度参数（`with_progress_args`）

| 参数 | 值 |
| --- | --- |
| `--newline` | — |
| `--progress` | — |
| `--no-color` | — |
| `--progress-delta` | `0.5` |
| `--progress-template` | `RAW\|%(progress.percent\|)s\|%(progress._percent_str\|)s\|%(progress.speed\|)s\|%(progress.eta\|)s\|%(progress.downloaded_bytes\|)s\|%(progress.total_bytes\|)s\|%(progress.total_bytes_estimate\|)s\|%(progress.fragment_index\|)s\|%(progress.fragment_count\|)s` |

字段顺序是解析器的硬契约，改动模板必须同步 `parsers/ytdlp_progress.rs`（见 `progress-and-diagnostics.md`）。

## 网络参数（`with_network_args`）

| 参数 | 值 | 来源 | 为空语义 |
| --- | --- | --- | --- |
| `--proxy` | 代理 URL | `network.enableProxy == true` 且 `network.proxy` 非空 | `enableProxy` 为 `null`/`false` 时不加 |
| `--impersonate` | `none` → 不加；`any` → 传空字符串；其它 → 原值 | `network.impersonate` | `"none"` 表示不模拟 |
| `--extractor-args` | 多行输入按行 trim、去空行后用空格连接 | `network.extractorArgs` | 规范化后为空时不加 |

可选值见 `src/helpers/network.ts` 的 `buildImpersonatePresets`（Chrome/Edge/Firefox/Safari/Tor 组合）。

## 认证参数（`with_auth_args`）

顺序：先 Cookie 相关（来自 `AuthSettings`），再钥匙串密文（`AuthSecrets`），密文可被组级 `auth` override 覆盖。

| 参数 | 值 | 来源 | 为空语义 |
| --- | --- | --- | --- |
| `--cookies-from-browser` | 浏览器名 | `auth.cookieBrowser` | 值为 `"none"` 时不加 |
| `--cookies` | 文件路径 | `auth.cookieFile` | `null` 时不加 |
| `--username` | 用户名 | `auth.username`（stronghold） | 缺省不加 |
| `--password` | 密码 | `auth.password`（stronghold） | 缺省不加 |
| `--video-password` | 视频密码 | `video.password`（stronghold） | 缺省不加 |
| `--add-header` | `Authorization:Bearer <token>` | `auth.bearer`（stronghold） | 缺省不加 |
| `--add-header` | 原样请求头（须含 `:`） | `auth.headers`（stronghold，按行存储） | 非法行在读取时被丢弃 |

- 认证字段**不得**写入日志或 Sentry：日志只记录"是否存在敏感 flag"（`RunLogSummary`：`arg_count`/`has_proxy`/`has_cookies`/`has_browser_cookies`/`has_auth`）。

## 字幕参数（`with_subtitle_args`）

前置条件（全部满足才会产生任何字幕参数）：
`subtitles.enabled == true` **且** `SubtitleInventory` 非空 **且** 解析后的语言列表非空。

| 参数 | 值 | 说明 |
| --- | --- | --- |
| `--write-subs` | — | 总是加 |
| `--embed-subs` | — | `embedSubtitles == true` 时 |
| `--no-write-auto-subs` + `--no-write-subs` | — | 嵌入模式下追加，避免留下独立字幕文件 |
| `--no-embed-subs` | — | `embedSubtitles == false` 时 |
| `--write-auto-subs` | — | 解析结果包含自动字幕时 |
| `--sub-format` | `a/b/c` | 首选格式在前，其余按 `srt/vtt/ass/ttml/json3` 补齐，`json` 归一化为 `json3` |
| `--sub-langs` | `lang1,lang2` | 只包含 inventory 中真实存在的语言；`all` 展开为全部可用语言 |

语言解析规则（`resolve_subtitle_request`）：

1. 存在组级 `manualLanguages`/`autoLanguages` 时按它们与 inventory 求交集；两者都为空则返回 `None`（不下字幕）。
2. 否则用全局 `languages`（`all` 表示全部）与 `includeAutoGenerated`。
3. 自动字幕按 base language 匹配，优先 `xx` 而非 `xx-orig`；当存在 `-orig` 变体时，忽略仅翻译版自动字幕。

## 格式参数（`with_format_args`）

### 音频（`trackType == audio`）

| 参数 | 值 |
| --- | --- |
| `-x` | 提取音频 |
| `-f` | `ba[language=xx]/ba[language=x]/ba/best`（有音轨偏好）或 `ba/best` |
| `-S` | `lang:<lang>`（无偏好时为 `lang`）→ `channels:<n>` → `abr~<abr>` → `acodec:<enc>` → 按目标容器追加编码/扩展名偏好 |

`-S` 尾部偏好映射：`m4a/aac` → `aext:m4a,acodec:aac`；`opus` → `acodec:opus,aext:webm`；`ogg` → `aext:ogg,acodec:vorbis`；`flac/wav` → `acodec:opus`；`mp3` → `aext:mp3`。

### 视频 / 视频+音频（`trackType == video|both`）

| 参数 | 值 |
| --- | --- |
| `-f` | 由 selector 列表用 `/` 连接，按"精确匹配 → 退化"顺序：`b[language=..]`、`bv*+ba`、`bv+ba`、`b`、以及去掉 fps/height 约束的变体 |
| `-S` | `lang:<lang|lang>` → `height:<h>` → `fps:<f>` → `vcodec:<enc>`（mp4 容器缺省 `avc1`）→（both）`acodec:<enc>`（mp4 缺省 `aac`）→ `vext:mp4,vext:m4a` 或 `vext` |

- `height`/`fps` 约束写作 `[height<=h]` / `[fps<=f]`；`TrackType::Video` 的 selector 不拼接音频。
- 音轨/视频轨偏好字符串格式为 `lang:<code>|channels:<n>`，`auto` 或空串视为无偏好。

## 输出与后处理参数（`build_output_args`）

固定前缀：`--output-na-placeholder ""`（模板字段缺失时输出空串而不是 `NA`）。

### 音频

| 条件 | 参数 |
| --- | --- |
| `policy == never` 且允许嵌入缩略图 | `--embed-thumbnail` |
| `policy == allowReencode` | `--audio-format <fmt>`；`--audio-quality <abr>k`（无则为 `0`）；允许时 `--embed-thumbnail` |
| `audio.postprocessPreset == custom` 且参数非空 | `--postprocessor-args ffmpeg:<args>` |

### 视频

| preset / policy | 参数 |
| --- | --- |
| `policy == never`（无 preset） | 仅 `--embed-thumbnail`（若开启） |
| `allowReencode` + `preset == none` | `--merge-output-format <mp4\|mkv>`、`--remux-video <容器>`、`--embed-thumbnail` |
| `preset == fps30`（要求允许重编码） | `--recode-video <容器>` + `--postprocessor-args VideoConvertor+ffmpeg:-vf fps=30` |
| `preset == mp42`（要求 mp4 容器） | `--merge-output-format mp4`、`--remux-video mp4` + `--postprocessor-args VideoRemuxer+ffmpeg:-brand mp42` |
| `preset == custom`（remux） | 容器 remux + `VideoRemuxer+ffmpeg:<args>` |
| `preset == custom`（reencode，要求允许重编码） | `--recode-video` + `VideoConvertor+ffmpeg:<args>` |

`custom` 参数会先用 `shlex::split` 校验引号/空格，非法则返回错误（前端表现为下载前的配置错误）。

| 参数 | 条件 |
| --- | --- |
| `--add-metadata` | `output.addMetadata` |
| `--write-thumbnail` | `output.saveThumbnail` |
| `--restrict-filenames` | `output.restrictFilenames` |
| `--download-sections *HH:MM:SS-HH:MM:SS` | `overrides.output.partialDownload.section` 存在 |
| `--no-embed-chapters` | 同上（部分下载时嵌入章节无意义） |

## 位置参数（`with_location_args`）

`-o <render_template(base_dir / directory_template / file_template)>`：

| trackType | 目录来源 | 文件名模板 |
| --- | --- | --- |
| `audio` | `preferences.paths.audioDownloadDir`，否则 `settings.output.downloadDir`，否则系统下载目录 | `output.audioFileNameTemplate` |
| `both` / `video` | `preferences.paths.videoDownloadDir`，同上回落 | `output.fileNameTemplate` |

模板变量（`TemplateContext.values`）由前端提供：`playlist_index`、`playlist_id`、`playlist_title`、`playlist`（同 title）、`playlist_uploader`、`playlist_uploader_id`、`playlist_count`、`n_entries`，后端补充 `autonumber`、`playlist_autonumber`。
渲染规则见 `template_context.rs`：支持 `%(field)s`、`%(a,b)s` 回退、`%(field&repl)s`、`%(field|default)s`、`%(num)03d`、`%%` 转义；未知字段保持原样交给 yt-dlp；已替换的值会把 `/` `\` `|` 与控制字符替换为 `_`（防目录穿越）。

## stdout / stderr 行契约

| 行形态 | 生产者 | 解析结果 |
| --- | --- | --- |
| `RAW\|…`（9 段） | 本应用的 `--progress-template` | `media_progress`（百分比、速率、ETA、分片进度） |
| `[download] Destination: <path>` | yt-dlp | 阶段 → `downloading`、类别按扩展名判定、`media_destination`（confidence 60） |
| `[download] <path> has already been downloaded` | yt-dlp | `media_destination`（confidence 65） |
| `[Merger] Merging formats into "<path>"` | yt-dlp | `media_destination`（`isMerged=true`，confidence 80）+ 阶段 `merging` |
| `[VideoRemuxer] Not remuxing media file "<path>"` | yt-dlp | `media_destination`（confidence 90） |
| 带 `Destination:` 的其它后处理行 | ffmpeg 后处理器 | `media_destination`，confidence 按标签：VideoConvertor 95 / VideoRemuxer 90 / Merger/ExtractAudio 70 / 其它 50 |
| `[VideoRemuxer]…` / `[VideoConvertor]…` | yt-dlp | 阶段 `remuxing` / `reencoding` |
| `[ffmpeg]`、`[Fixup]`、`Deleting original file` | yt-dlp | 阶段 `finalizing` |
| `frame=… time=HH:MM:SS.ss … speed=1.2x` | ffmpeg（部分下载时） | `media_progress`，百分比 = 已处理时长 / 目标区段时长 |
| `ERROR: …` / `WARNING: …` | yt-dlp | `media_diagnostic` |
| `… has already been recorded in the archive` 等跳过文案 | yt-dlp | `media_diagnostic`（`code=input_filter_skipped`，level warning） |
| 其它行 | — | 仅写入日志 |

## 退出码与错误映射

| 情况 | 后端行为 | 事件 |
| --- | --- | --- |
| 退出码 `0` | `Ok(())` | `media_complete` |
| 退出码非 0 | `Err(NonZeroExit(code))` | `media_fatal`（带 exit code） |
| 无法启动进程 | `Err(SpawnFailed)` | `media_fatal`（`internal=false`，exit code 1）+ Sentry |
| 内部错误（规则文件损坏、事件流中断、运行器错误） | 对应 `Err(...)` | `media_fatal`（`internal=true`）+ Sentry |
| 参数构造失败 | `Err(InvalidArguments)` | `media_fatal`（`internal=true`），进程未启动 |
| 用户取消 | `Ok(())` | 无（不写 fatal/complete） |

Sentry 白名单（`download_pipeline.rs`）：`SpawnFailed`、`InvalidDiagnosticRules`、`EventStreamEnded`；
抓取侧为 `InvalidDiagnosticRules`、`RunnerFailed`、`ParseFailed`。业务性失败（非 0 退出）不上报。

## Failure And Edge Cases

- 进度模板字段为空时解析器会退化到"用 downloaded/total 估算"或"用分片比例估算"，都拿不到则**丢弃该行**。
- `--output-na-placeholder ""` 与 `TemplateContext` 的"未知字段保持原样"共同保证：未提供的模板字段最终由 yt-dlp 自己填。
- 若目标容器为 `mp4`，`-S` 会倾向 `avc1`/`aac`/`vext:mp4`；这会影响最终文件的实际编码，属于设计取舍而非缺陷。

# media-queue 数据模型

## Purpose

列出队列侧的全部数据结构、字段语义与生命周期。所有结构定义在前端 `src/tauri/types/*.ts`，
只有下发到后端时才序列化（`DownloadItem`、`FormatOptions`、`DownloadOverrides` 在 Rust 侧有对应定义）。

## Current Behavior

### Group（`src/tauri/types/group.ts`）

| 字段 | 类型 | 来源 | 说明 |
| --- | --- | --- | --- |
| `id` | `string` | 前端 uuid | 队列条目主键，路由参数 `groupId` 即此值 |
| `total` | `number` | `media_add.total` | 期望条目数 |
| `processed` | `number` | 前端自增 | 已返回的条目数（成功或失败） |
| `errored` | `number` | 前端自增 | 失败条目数 |
| `isCombined` | `boolean` | `finalizePlaylistGroup` | 是否合并组 |
| `items` | `Record<string, MediaItem>` | 前端 | item 集合；单条 group 通常只有 1 个 |
| `url` | `string` | 入队 URL | 重试时复用 |
| `title` / `thumbnail` / `description` / `uploader` / `uploaderId` / `extractor` / `views` / `comments` / `likes` / `dislikes` / `rating` / `duration` | 可选 | 首个成功 item 的元数据回填 | 合并组在 `consolidateGroup` 时用 leader 覆盖 |
| `audioCodecs` / `videoCodecs` / `audioTracks` / `videoTracks` / `formats` | 数组 | 解析结果 | 合并组会去重合并 |
| `chapters` | `Chapter[]` | 解析结果 | 用于部分下载的章节选择 |
| `entries` | `EntryItem[]` | 播放列表解析结果 | 存在即代表"播放列表 leader" |
| `filesize` | `number` | 解析结果 | yt-dlp 的 `filesize` 或 `filesize_approx` |
| `playlistId` / `playlistTitle` / `playlistCount` / `playlistUploader` / `playlistUploaderId` | 可选 | 播放列表元数据 | 模板变量来源 |
| `fromShortcut` | `boolean` | 入队渠道 | 快捷方式入队的通知强制弹出（`force=true`） |
| `skipPlaylistSelection` | `boolean` | "add and download" / 剪贴板自动下载 | 跳过选择 UI，直接抓全部条目 |

### MediaItem

在 `Group` 字段基础上补充：`id`、`url`、`isLeader`、`groupId`、`playlistIndex`、`subtitleInventory`、`overrides`。
`isLeader = true` 的 item 不参与下载，只承载 group 状态与元数据。

### MediaFormat

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | `string` | yt-dlp format id |
| `height` / `fps` | `number?` | 视频分辨率与帧率（音频格式为空） |
| `abr` | `number?` | 音频码率 kbps |
| `audioCodecs` / `videoCodecs` | `MediaCodec[]` | `string` 或 `{ id, label }` |
| `audioTrackIds` / `videoTrackIds` | `string[]?` | 该格式包含的音轨/视频轨 id，用于"某分辨率下可选轨"提示 |

### MediaTrack

`{ id, label, language?, languagePreference?, formatNote?, format?, audioChannels? }`；`id === "auto"` 表示自动选择，UI 会过滤掉。

### DownloadOptions（前端内存）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `trackType` | `"both" \| "audio" \| "video"` | 决定 selector 与输出模板 |
| `height` / `fps` / `abr` | `number?` | 目标分辨率/帧率/码率 |
| `audioEncoding` / `videoEncoding` | `string?` | 目标编码（`-S acodec:…/vcodec:…`） |
| `audioTrack` / `videoTrack` | `string?` | 音轨/视频轨选择，形如 `lang:en|channels:2` 或 `auto` |
| `id` / `videoCodecs` / `audioTrackIds` / `videoTrackIds` | 辅助 | 仅前端使用 |

### DownloadOverrides（组级覆盖，只存差异）

```
DownloadOverrides {
  output?: { video?: {...}, audio?: {...}, addMetadata?, addThumbnail?, saveThumbnail?,
             preciseCuts?, reversePlaylistNumbering?, fileNameTemplate?, audioFileNameTemplate?,
             restrictFilenames?, partialDownload?: { section?: { id, start, end } } }
  auth?: { cookieFile?, cookieBrowser?, username?, password?, videoPassword?, bearerToken?, headers? }
  network?: { enableProxy?, proxy?, impersonate?, extractorArgs? }
  subtitles?: { enabled?, includeAutoGenerated?, languages?, manualLanguages?, autoLanguages?, formatPreference?, embedSubtitles? }
  sponsorBlock?: { apiUrl?, removeParts?, markParts? }
  input?: { preferVideoInMixedLinks? }
  inputFilters?: { playlistItems?, minFilesize?, maxFilesize?, date?, datebefore?, dateafter?,
                   matchFilters?, breakMatchFilters?, playlistMode? }
}
```

- 字段为 `undefined` 表示"继承全局设置"；后端 `resolve_with_patch` 逐字段判断，不做整体替换。
- 写入前 `useMediaOptionsStore.setOverrides` 会 `structuredClone(toRaw(...))` 并 `markRaw`，避免 Vue 响应式代理泄漏到 IPC。
- 合并组拆分时 `migrateOverrides` 把同一份 override 复制到每个新 group，并删除旧 group 的 override。

### SubtitleInventory

`{ manualLanguages: string[], autoLanguages: string[] }`：该视频**真实存在**的字幕语言（小写、去重、排序）。
后端 `resolve_subtitle_request` 用它把用户"想下"的语言收敛为"能下"的语言；为空时不产生字幕参数。

### PlaylistSelection

```
{ rows: Array<{ id, type: 'single', index } | { id, type: 'range', start, end }> }
```

- 索引语义：`1` 起；负数表示从末尾倒数（`-1` 为最后一条）；`0` 视为空。
- 规范化（`normalizePlaylistSelection`）：丢弃空行、非整数置空、`0` → 空。
- `buildPlaylistItemsSpec` 产出 `playlist_items` 字符串；`applyPlaylistSelectionToEntries` 产出被选中的 entries（按选择顺序、按 index 去重）。

### MediaState

`fetching | fetchingList | playlistSelection | configure | downloading | downloadingList | paused | pausedList | error | done`
（`src/stores/media/state.ts`，`const enum`）。

| 状态 | 触发条件 | 组件 |
| --- | --- | --- |
| `fetching` | 单条入队 | `FetchStep` |
| `fetchingList` | 播放列表条目抓取中 | `FetchListStep` |
| `playlistSelection` | 播放列表等待选择 | `PlaylistSelectionStep` |
| `configure` | 可下载/可配置 | `MediaConfigureStep` |
| `downloading` / `downloadingList` | 下载中（单条/合并组） | `MediaDownloadStep` / `MediaDownloadListStep` |
| `paused` / `pausedList` | 已暂停 | `MediaPausedStep` / `MediaPausedListStep` |
| `done` | `media_complete` | `MediaDoneStep` |
| `error` | `media_fatal` | `MediaErrorStep` |

只有 leader item 持有 group 状态；`setGroupState`/`getGroupState` 通过 `findGroupLeader` 间接读写。

## Boundaries

- Rust 侧没有队列模型：`Group`/`MediaItem` 只存在于前端，后端只见到 `DownloadItem`。
- `DownloadOptions` 与 `FormatOptions` 字段基本同构：前端把 `audioEncoding`/`videoEncoding`/`audioTrack`/`videoTrack` 一并塞进 `FormatOptions` 下发。
- `MediaState` 是前端概念，后端不知道状态机，只通过事件驱动迁移。

## Contracts

- 下发字段的 Rust 对应定义：`src-tauri/src/models/download.rs`。
- 覆盖解析规则：`src-tauri/src/runners/override_resolver.rs`。
- 模板变量：`src-tauri/src/runners/template_context.rs` 与 `download-engine/api-contract.md`。

## Failure And Edge Cases

- 同一 URL 出现多次会生成多个独立 item（不同 `groupId`/`id`），不做全局去重。
- `consolidateGroup` 用 `(height, fps)` 作为格式去重键，码率不同的音频不会进入 formats 去重（按 `abr` 区分）。
- 合并组 leader 的 `duration` 是组内时长之和，与单条语义不同。
- `media_add` 到达但 group 不存在时抛 `Orphaned media item found.`。
